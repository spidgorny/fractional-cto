# Project guide

## Overview

Small Vite + React landing page for fractional CTO services.

## Common commands

- `npm install` — install dependencies
- `npm run dev` — start Vite dev server (http://localhost:5173/)
- `npm run build` — production build to `dist/`
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint

## Technology stack

- Vite 8
- React 19
- JSX components in `src/components/`
- Global styles in `src/index.css` and `src/App.css`
- No tests configured

## Conventions

- Components are functional and default-exported from `src/components/*.jsx`.
- Keep copy concise and founder-focused.
- Avoid adding runtime dependencies unless necessary.
